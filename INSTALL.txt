## 🔍 Lo que Hace el Programa

1. Lee 100,000 palabras del archivo dataset.txt
2. Ejecuta 3 algoritmos de ordenamiento:
   - QuickSort (partición)
   - HeapSort (montículo)
   - AVL Tree (árbol balanceado)
3. Mide tiempo de ejecución de cada uno
4. Verifica que todos produzcan un ordenamiento correcto
5. Estima uso de memoria
6. Muestra comparativa de rendimiento
